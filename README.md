### 🚀 About Me

I am a passionate **University Student** specializing in game design, web development, and digital experiences. I love creating interactive spaces on the web—bridging the gap between design and functionality.

* 🎓 **Focus:** Game Design, Development & Modern Web Technologies.
* 🕹️ **Arcade Project:** Building and curating web-based classic games, retro ports, and modern responsive layouts.
* 💡 **Tech Interest:** Exploring dynamic front-end libraries, performance optimization, and WebGL/Three.js.

---

### 🔭 Currently Working On...

* 💻 **The Arcade:** Adding multiplayer/retro web ports (including Eaglercraft/Minecraft) to my [HTML5 Web Arcade](https://unitybtw.github.io/sirac-portfolio/).
* ⚡ **Performance:** Tuning iframe latency, touch controls, and input handling for cross-platform play.
* 🎯 **Goal:** Providing an ad-free, high-performance web gaming playground for students worldwide.
